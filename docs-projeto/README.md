## 📖 Como Usar Esta Documentação

### Para Começar

1. Leia o [README.md](../README.md) principal
2. Siga o [GUIA_RAPIDO_PT.md](GUIA_RAPIDO_PT.md) para configuração inicial
3. Configure CI/CD com [GITLAB_CI_SETUP.md](GITLAB_CI_SETUP.md)

### Para Desenvolvimento

1. Consulte [PROJECT_STRUCTURE.md](PROJECT_STRUCTURE.md) para entender a estrutura
2. Use [QUICK_REFERENCE.md](QUICK_REFERENCE.md) para comandos comuns
3. Siga [DEPLOYMENT_CHECKLIST.md](DEPLOYMENT_CHECKLIST.md) antes de fazer deploy

### Para Troubleshooting

1. Verifique [FIX_SUMMARY.md](FIX_SUMMARY.md) para problemas conhecidos
2. Consulte [MKDOCS_WARNINGS_GUIDE.md](MKDOCS_WARNINGS_GUIDE.md) para warnings
3. Revise [GITLAB_CI_NOTES.md](GITLAB_CI_NOTES.md) para problemas de CI/CD

## 📝 Convenções

### Nomenclatura de Arquivos

- **UPPERCASE.md** - Documentação principal
- **lowercase.md** - Documentação secundária
- **NOME_PT.md** - Versão em português
- **.extensão.documented** - Versão documentada de arquivos de configuração

### Estrutura de Documentos

Todos os documentos seguem esta estrutura:
1. Título principal
2. Resumo/Overview
3. Conteúdo detalhado
4. Exemplos práticos
5. Troubleshooting (se aplicável)
6. Links relacionados

## 🔄 Manutenção

### Atualizar Documentação

1. Edite o arquivo relevante
2. Atualize a data no rodapé
3. Adicione entrada no changelog (se houver)
4. Commit com mensagem descritiva

### Adicionar Nova Documentação

1. Crie o arquivo na pasta apropriada
2. Adicione ao índice deste README
3. Link de documentos relacionados
4. Commit e push
